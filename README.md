## 🎯 Cíl projektu
Vytvořit **webovou aplikaci na téma sigleplayer quiz hra s odděleným frontendem a backendem, splňující tyto požadavky:
- REST API
- databázové úložiště (např. PostgreSQL / MariaDB)
- minimálně 3 unit testy
- dokumentace (UML, SWOT, EPC…)

## ⚙️ Použité technologie
- Backend: Java (Spring Boot)
- Frontend: React
- Databáze: PostgreSQL
- Verzování: Git + GitHub
